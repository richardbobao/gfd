# 🛒 TechStore - Loja Virtual Fictícia

Projeto de loja virtual interativa e responsiva desenvolvido com **HTML5, CSS3 e JavaScript puro**, publicado via GitHub Pages.

## 🚀 Funcionalidades
- **Catálogo Dinâmico**: Exibição de 12 produtos com nome, preço, imagem, descrição, badge de promoção e avaliação por estrelas.
- **Filtros e Busca**: Pesquisa em tempo real por nome/descrição e filtragem por categoria.
- **Carrinho de Compras**: Adição/remoção de itens com cálculo de total em tempo real.
- **Favoritos**: Adição e gestão de lista de desejos.
- **Modo Escuro (Dark Mode)**: Suporte a alternância de tema visual.
- **Checkout**: Tela de simulação de finalização da compra.
- **Layout Responsivo**: Adaptado para telas mobile, tablets e desktops.

## 🛠️ Tecnologias
- HTML5 Semântico
- CSS3 (Variables, Flexbox, Grid, Data-Attributes)
- JavaScript (Manipulação de DOM, Arrays e Eventos)
